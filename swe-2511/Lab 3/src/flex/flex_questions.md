### Flex Container Properties
 - flex-wrap – Allows items to wrap to a new line if they don’t fit. 
 - justify-content – Aligns items along the main axis (left, center, space-between). 
 - align-items – Aligns items along the cross-axis (top, center, bottom). 
 - align-content – Spaces multiple rows of items along the cross-axis. 
 - gap – Sets spacing between items without margins. 
### Flex Item Properties 
 - order – Changes the visual order of items. 
 - flex-grow – Controls how much an item expands to fill space. 
 - flex-shrink – Controls how much an item shrinks when space is tight. 
 - flex-basis – Sets the starting size of an item. 
 - align-self – Overrides container alignment for one item

### Comparison of Flex and Flow
 - Flex is easier for complex, row/column layouts because it’s built for aligning and distributing space among items. A few properties handle what would take many rules in flow layout. 
 - Flow layout is simpler for basic text + image pages, but becomes harder when layouts need spacing, centering, or responsiveness.
