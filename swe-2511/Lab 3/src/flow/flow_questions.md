### Flow Layout Research
 - The flow layout (normal flow) is the default in HTML. 
 - Elements stack top-to-bottom if block-level, and left-to-right if inline. 
 - Browsers handle placement unless overridden with CSS.
### Display Property Research
 - block – Takes full width, starts on a new line. (Use for paragraphs, divs, sections). 
 - inline – Flows with text, only as wide as content. (Use for links, spans). 
 - inline-block – Flows inline but keeps block-like sizing (width/height). (Use for nav items, buttons).
