## Webpack
A web bundler that can transform and bundle almost any asset to static files

Advantage: Large and stable plugin ecosystem  
Disadvantage: Slow compared to esbuild

## esbuild
A modern web bundler written in go that uses multi threading to achieve high performance

Advantage: Really fast  
Disadvantage: Limited plugin support compared to vite
