- Both local storage and session storage save data on the local storage of the web page's origin server.  
- Local storage does not expire and is kept forever.  
- Session storage saves data on the local storage of the web page's origin server. Data in session storage is deleted after the tab the website is running in is closed.  
- You might use local storage to store data for a simple website if you do not want to create or
host your own API for data.  
- You might use session storage to save inputs in a form to protect against accidental refreshes
if the form is long.
