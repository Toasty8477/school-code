## Mocha
Mocha is a testing framework for javascript

Features:
* Runs in the browser as well as the terminal
* inline differences support
* promise and async support
* node debugger support
* and more!

How to install:  
`npm install --global mocha` or `npm install --save-dev mocha`

How to import:  
`import assert from "assert"`

[Source](https://mochajs.org/)

## Socket.io
A library that provides a framework for websocket, webtransport, or http long-poling communication between servers and clients.

Features:
* http fallback
* automatic reconnection
* packet buffering
* acknowledgements
* broadcasting
* multiplexing

How to install  
Client: `npm install socket.io`  
Server: `npm install socket.io-client`  

How to import:
Server: `import { Server } from "socket.io"`
Client: `import { io } from "socket.io-client`

[Source](https://socket.io/)
